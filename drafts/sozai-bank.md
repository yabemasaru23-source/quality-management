# 素材バンク（矢部大 一次情報）

ブログ記事の原料。ここに貯めた事実だけを使って記事を書く。
Webで調べられることは書かない。**矢部大の記憶にしかないもの**だけを入れる。

答え方のルール：
- 文章にしなくていい。単語・箇条書き・言い間違いのままで構わない
- 数字は「たしか」で構わない。あとで確認する
- 思い出せない問いは飛ばす。全部埋める必要はない
- 音声入力で喋ってそのまま貼り付けても可

## A. 数字（記事に「重さ」を出す原料）

**A1. 大人向けバク転講座、いちばん最初の開催。参加者は何人でしたか。参加費はいくらでしたか。**
→ **基本はパーソナルトレーニング形式。1日4人が限界。参加費は1人18,000円。**
→ ※要確認：冒頭で「初回48人」という数字も出たが、1日4人限界との関係が未確定（初回だけイベント形式だった？ 別の何かの48人？）

**A2. その初回、売上はいくらでしたか。そして経費を引いて手元に残ったのはいくらでしたか。**
→ **売上の50%が手残り（粗利率50%）。**

**A3. 参加費を上げたことがあるはずです。何円から何円にしましたか。そのとき何人が離れましたか。**
→ **値上げしていない。18,000円をずっとキープ。**（※これ自体が記事1本になる。「値上げしない」という選択）

**A4. 講座を「これは事業になる」と確信したのは、何回目の開催でしたか。何がそう思わせましたか。**
→ **1回目から。決定的だったのは開始1か月ほどで取材が来はじめたとき。**
→ **経済誌に取り上げられ、テレビ取材は年間30回ほど。予約は3か月先まで満席。**

**A5.（質問を作り直し）バク転講座1本から、タレント事務所・派遣事業へ広がっていきました。最初に「講座以外」を始めたのは何がきっかけでしたか。誰かに頼まれたのか、自分で仕掛けたのか。**
→

**A6. 累計10億円。その内訳をざっくり言うと、どの事業が何割ですか。**
→ **派遣事業 6割／芸能 4割。**

**【重要・書き方の注意】10億の作られ方（本人による訂正）**
- スタジオを増やして場所を広げ、1日最大20人程度まで教えられるようになった
- **ただしバク転講座単体では10億には絶対に届かない。ここを混同して書かないこと**
- 実際の流れ：講座が有名になる → 人が集まる → マスコミ露出（経済誌・テレビ年30回）→ さらに人が集まり社員が増える → **その人員を使って派遣会社・派遣事業へ展開** → ここが売上の6割
- 正しい言い方は「バク転講座**が入り口**となり、そこから会社と事業が増えていった」
- ❌「1日4人の講座で10億をつくった」→ 事実と異なる。使用禁止

## B. 失敗・恥（いちばん読まれるが、いちばん書きにくい部分）

**B1. 畳んだ事業、撤退した事業はありますか。何をいくら失いましたか。**

**B2.（質問を作り直し）一緒に事業を作ってきた人が離れていった経験はありますか。あるとしたら、どういう別れ方でしたか。**
→

**B3. 資金繰りで眠れなかった時期はありますか。いつ、いくら足りませんでしたか。**
→ **「資金繰り」というより回収の問題。売掛・買掛の回収が滞ったとき。**
→ **助成金が下りなかったとき。**
→ **インシデントを起こされ、6,000万円の請求書が送られてきたとき。これは本当に眠れなかった。**
→ ※要確認：この6,000万の件は何が起きたのか（事故／訴訟／取引先絡み）。記事にするなら核心。

**B4. 提案して断られた案件で、いまでも覚えているものは。断られた理由は何と言われましたか。**
→ **フジテレビまで行き、ドキュメンタリー番組に自分が出たいと売り込んだ。断られた。**
→ **理由：「あなたはドキュメンタリーに出るには力不足。もっと幸せな環境にいる。ドキュメンタリーに出るのは、もっと悲惨な人だ」と言われた。**
→ 本人の総括：断られたことより、その内容で自分の立ち位置が分かった。
→ ※注記：本人は「役不足」と表現。記事化する際は誤用にならない言い回しに調整すること。

**B5. ギネス記録の当日、いちばん焦った瞬間は何が起きたときですか。（2012東京140人／2022福岡161人 どちらでも）**

→ **【2012年 東京・140人】当日、雨が降ってきた。**
　　いちばんの心配は記録ではなく**怪我人が出ないか**だった。

→ **【2022年 福岡・161人】怖かったのは「そもそも人が集まるのか」。**
　　マスコミ20社以上が取材に来た（NHKほか、全国放送された）。
　　その状況で**本当に161人以上が集まるのか**が怖かった。
　　**実際には180人ほどが集まり、161人が成功**（と記憶）。
　　本人の言葉：**「そもそも土俵に乗れるかどうかが怖かった」**

→ ※記事の芯：注目が集まることの恐ろしさは「失敗」ではなく「**土俵にすら乗れないこと**」。
　　180人来て161人成功 ＝ **全員が跳べたわけではない**。この数字の差もそのまま使える。

**B6. 「あのとき決断が遅れた」と思う件はありますか。何日／何か月遅れましたか。**
→ **思い当たる案件は特にない。「経営者の決断は即決が基本」という考え方。**
→ ※これ自体が素材。遅れた例が出てこないこと＝即決を信条として貫いてきたということ。

## D. 決断の瞬間（記事の山場になる）

**D1. 26歳でワーサルを設立。会社にする決め手になった出来事は何でしたか。**

→ **【最重要素材】ワーサルは「クオリティマネジメントを継ぐための実践勉強の場」として作られた。**

- そもそも**クオリティマネジメントを引き継ごう**と考えていた
- 当時、父・**矢部廣重の講座「社長のためのセールス革命」をサポート**していた
- そこで気づいた：**社長にならなければ、この講座は本当には響かない／身につかない**
- ならば自分でゼロから会社を起こし、**どれだけノウハウを蓄積でき、どう営業につなげられるかを実践で学ぶ**——そのために会社を作ると判断した

→ ※つまり **バク転は目的ではなく、経営を学ぶための実験場だった。**
→ ※QMのブログに載せる記事として最も筋が通る話。「なぜアクションの会社を作ったのか」の答えが「コンサルタントになるため」である、という構造。

**D2. 「大人向けバク転講座」を思いついた瞬間。どこで、何を見て、何を考えていましたか。**

→ **顧客の声から生まれた。自分のアイデアではない。**

- もともと**アクションスクール**を運営していた
- ところが、アクションを習いに来る人より **「バク転をやりたい」という人が多数**いた
- レッスンの**前半がバク転・体操の時間**だったが、参加者が口々に「バク転、バク転、バク転」と言う
- → **バク転に特化した講座を作ろう**と決めた

→ ※記事の芯：**日本初の事業は、ひらめきではなく「客が繰り返し言っていた言葉」から生まれた。**
　　顧客の声の聴き方というテーマで、そのまま1本書ける。

**D3. ギネスに挑戦すると決めたのは誰の発案でしたか。反対はありましたか。**

→ **発案は矢部大ではなく、スタッフからの提案。**
→ 反対の理由は **予算**。ギネス世界記録への挑戦というだけで **数百万円の経費**がかかる。

→ ※記事の芯：会社の代名詞になった実績（2度のギネス）が、**社長の発案ではなかった**という事実。
　　「任せる」「現場の提案を採る」というテーマに直結する。

**D4. 人に初めて仕事を任せたとき、何を任せて、どう失敗しましたか。**

→ 「初めて」という特定の記憶はない。**「とりあえず任せる」を念頭に経営している。**
→ 矢部廣重の教え：**できたことに対しても、できなかったことに対しても褒める**
→ 好きな言葉は山本五十六の
　　**「やってみせ、言って聞かせて、させてみせ、褒めてやらねば、人は動かじ」**
　　※本人の引用は口頭のため一部不正確。記事に載せる際は上記の正しい表記を使うこと。

**D5. 18,000円を一度も上げていません。上げようと思ったことはありますか。上げなかったのはなぜですか。**

→ **【値決めの核心】語られたのは「上げない理由」ではなく「下げない理由」だった。**

- **「価格を下げれば人が集まる」という考え方は、根本的に大きな間違い**
- 価格をいじる前に、**まず営業手法を考える**
- **下げた金額は、二度と元には戻せない**
- だからこそ営業マンであること、**営業が頭を百倍考えること**（＝C4・父の教え「百倍考え抜く」）に直結する

→ ※18年間 18,000円を据え置いた＝**上げもしないが、下げもしなかった**という一貫性。
→ ※要確認：「上げなかった理由」は未回答。値上げを検討したことはあるのか。

## E. 現場のディテール（記事の書き出しに使う）

**E1. 講座の会場で、開始5分前にあなたが必ずやっていることは。**

→ ※感動セールスの実務そのもの。「予想 < 現実」を起こすには、開始前に相手の予想を知っている必要がある。

→ **探しているのは「共感できるものがあるか」。**
→ ※書棚は社長の思考の履歴。提案の前に、まず共通点を見つけにいっている。
