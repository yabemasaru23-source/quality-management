# 命式のダブルチェック

命式は1文字違えば、その人に伝わる人生の解釈が変わります。
**同じ人が同じ考え方で2回計算しても、同じ間違いをするだけです。**
そこで、本体とは別に独立実装をもう1つ置き、機械に突き合わせさせています。

## 中身

| ファイル | 役割 |
|---|---|
| `independent-engine.js` | 本体(`../index.html`)とは別に書き起こした第2の計算エンジン |
| `crosscheck.js` | 両者を数千件の生年月日で突き合わせる。1件でも違えば異常終了 |

## 使い方

```bash
node verify/crosscheck.js          # 既定 20,000 件
node verify/crosscheck.js 5000     # 件数を指定
node verify/crosscheck.js --full   # 1900〜2050年の全日付
node tests/verify.js               # 人間が検証済みの鑑定書との回帰テスト
```

**`index.html` の計算部を触ったら、必ず両方を通してください。**

## 突き合わせている項目

干支（四柱）／蔵干／通変星／蔵干通変星／十二運星／運勢エネルギー／
天中殺（日柱・年柱）／五行の数／節入りの節名と日数／年柱の基準年

## 対象外にしているもの

**節入り当日**に生まれた場合は集計から外しています。
本体は節入りを「日付」で判定し、伝統的な流派は「時刻」で判定します。
全体の約1.8%で結果が変わる論点で、どちらを採るかは流派の選択です。
バグではないため、検証の合否には含めていません。

## 流派として確定している約束

鑑定士作成の解説書（大森玲さん 1977-11-11 17時）で確認済みのものです。
これらは「実装の違い」ではなく「流派の決め」なので、両エンジンで揃えます。

- 節入りからの日数は**暦日**で数え、節入り当日を1日目とする
- 蔵干は月柱だけでなく**四柱すべて**に「節入りからの日数」を当てる
- 巳の蔵干配分は 戊7日 / 庚14日まで / 以降 丙（寅・申・亥と同じ形）

## これができた経緯

2026年9月、大雪（黄経255度）の節入りが前年の日付になる不具合が見つかりました。
12月7日〜31日生まれの月柱が誤り、納品済みの鑑定書にも影響しました。
本体だけを見ていては気づけなかったため、独立実装との突き合わせを常設にしています。
